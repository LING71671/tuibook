# Contributing to TUIBook

Use JDK 21 and the Gradle Wrapper. Start from the current `main` branch and name your branch after the change, such as `feature/source-validation`.

1. Keep each pull request focused on one change and describe what it does.
2. Run `./gradlew build`, or `.\gradlew.bat build` on Windows. Describe the checks you performed in the pull request.
3. Open the pull request against `main`. Review the diff and wait for both CI jobs to pass before merging.

Write repository documentation and commit messages in English. Keep local book files, credentials, and generated reports out of commits.
